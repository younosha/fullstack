# Fullstack Products App

Monorepo application with:

- React
- TypeScript
- Vite
- Redux Toolkit

- NestJS
- Prisma
- SQLite

Первый запуск:
1) cp apps/api/.env.example apps/api/.env &&
2) npm install &&
3) cd apps/api &&
4) npx prisma migrate dev &&
5) cd ../.. &&
6) npm run dev

Дальше просто npm run dev для запуска

BACK: http://localhost:3000
FRONT: http://localhost:5173
